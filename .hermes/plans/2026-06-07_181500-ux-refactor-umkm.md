# Noblesoft UI/UX Refactoring Plan (The "Innocent User" Protocol)

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Refactor the Noblesoft frontend to be highly intuitive and accessible for non-technical UMKM (Micro, Small, and Medium Enterprises) users by eliminating technical jargon, improving error messages, and making interactions less intimidating.

**Architecture:** We will modify existing React components and pages in the Next.js frontend (`frontend/src/`). The changes are primarily text replacements, UX copy improvements, and state-driven feedback additions. No major architectural overhauls are needed.

**Tech Stack:** Next.js (React), Tailwind CSS, Lucide Icons, TypeScript.

### Task 3: Friendly Error Messages on Login & Register

**Objective:** Ensure error messages don't sound like system failures but rather helpful nudges. Also, add live validation feedback for the password.

**Files:**
- Modify: `D:/STUDY/Kuliah/flutter/PROJECT/noblesoft/frontend/src/app/login/page.tsx`
- Modify: `D:/STUDY/Kuliah/flutter/PROJECT/noblesoft/frontend/src/app/register/page.tsx`

**Step 1: Soften Login Errors**
In `login/page.tsx`:
Currently:
```typescript
      let errorMessage = err.message || 'Gagal masuk. Silakan coba lagi.';
      if (err.message?.toLowerCase().includes('invalid')) {
        errorMessage = 'Email atau password salah. Yuk, coba periksa kembali!';
      }
```
Update to be even more friendly:
```typescript
      let errorMessage = 'Aduh, sistem sedang sibuk. Boleh coba sebentar lagi?';
      if (err.message?.toLowerCase().includes('invalid') || err.message?.toLowerCase().includes('credentials')) {
        errorMessage = 'Hmm, sepertinya Email atau Password-nya keliru. Coba dicek lagi ya!';
      }
```

**Step 2: Add Real-time Password Feedback in Register**
In `register/page.tsx`:
Add a small hint text below the password input that changes color based on length.
```tsx
  {/* Password input */}
  <div className="space-y-1.5">
    <label htmlFor="password" className="text-xs font-medium flex items-center gap-2 text-brand-teal">
      <Lock className="w-3.5 h-3.5 text-accent" />
      Password (Kata Sandi)
    </label>
    <Input
      id="password"
      type="password"
      placeholder="Ketik rahasia Anda di sini..."
      value={password}
      onChange={(e) => setPassword(e.target.value)}
      required
      minLength={6}
      disabled={loading}
      className="h-10 glass-input text-sm"
    />
    {password.length > 0 && password.length < 6 && (
      <p className="text-[10px] text-destructive mt-1">Kata sandi kurang panjang (minimal 6 huruf/angka).</p>
    )}
    {password.length >= 6 && (
      <p className="text-[10px] text-emerald-600 mt-1">Kata sandi sudah aman!</p>
    )}
  </div>
```

**Step 3: Commit**
